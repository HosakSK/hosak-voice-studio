Piper Voice-Over Studio • User Guide

How it works:

  • The app uses the neural text-to-speech engine Piper TTS running directly in your browser via WebAssembly & ONNX Runtime Web.
  • On first use of a selected voice, the neural model (~35 MB) is downloaded and cached in your browser storage (OPFS / CacheStorage). Every subsequent generation runs instantly and works offline!
  • Speaking Speed: Adjusts pacing and tempo without altering vocal pitch.
  • Tone Variability (noise_scale): Increases vocal expression and intonation dynamics (higher = more expressive, lower = more steady/monotone).
  • Insert Pause: Inserts an ellipsis marker or pause token to create natural breathing pauses between sentences.
  • Keyboard Shortcuts: Ctrl + Enter (Generate), Spacebar (Play / Pause).
